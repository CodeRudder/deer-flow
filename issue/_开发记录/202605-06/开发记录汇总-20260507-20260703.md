## 01｜20260630-20260703

### 📌 本周重点
- 持久化与视觉模型基础：补齐 PostgreSQL 依赖和独立视觉模型配置，为存储及图片理解能力落地提供基础。
- 图像生成配置体系：支持 OpenAI 图像 API 版本配置并收敛提供商范围，提升图像接口适配性。
- 平台入口体验：首页路由和网关不可用页面形成完整入口反馈，改善服务异常时的用户感知。

### ✨ 新功能
- 更新依赖配置以支持 PostgreSQL 功能，补齐后端持久化存储所需依赖。
- 新增独立视觉模型配置能力，使图片识别/理解可以使用独立模型配置，减少对主对话模型的限制。
- 为 OpenAI 图像生成增加 API 版本配置支持，提升不同 OpenAI 图像接口版本的适配能力。
- 实现首页路由重定向逻辑，并新增网关不可用页面，改善服务异常时的用户提示。

### 🐛 bug 修复
- 修复推理组件持续时间显示问题，改善前端推理状态展示准确性。

### 🔧 功能改造
- 优化消息列表中的子任务更新逻辑，减少子任务状态刷新带来的展示异常。
- 优化动态上下文中间件的注入目标选择逻辑，使上下文注入更精准。
- 移除 Gemini 图像生成提供商并更新相关配置，收敛当前图像生成提供商范围。
