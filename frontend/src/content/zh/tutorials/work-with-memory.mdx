# 使用记忆系统

本教程介绍如何在 DeerFlow 中启用和使用记忆系统，让 Agent 在多次会话中记住关于你的重要信息。

## 启用记忆

在 `config.yaml` 中启用记忆：

```yaml
memory:
  enabled: true
  injection_enabled: true
  max_injection_tokens: 2000
  debounce_seconds: 30
```

如果你想继续让长期记忆在后台学习和保存，但暂时不注入到后续对话中，保持 `enabled: true`，并设置 `injection_enabled: false`。

## 记忆的工作方式

记忆通过 `MemoryMiddleware` 自动工作：

1. **第一次对话**：告诉 Agent 关于你的偏好、项目或背景。
2. **自动学习**：Agent 在后台提取并保存重要事实。
3. **后续对话**：记忆事实会自动注入到隐藏的 system-reminder 上下文中，除非关闭 `injection_enabled`。Agent 无需你重新解释背景。

## 示例

**第一次对话**：

```
我是一名 Python 后端开发者，主要使用 FastAPI 和 PostgreSQL。
我的团队遵循 PEP 8 代码规范，偏好类型注解。
请记住这些信息，在以后的代码建议中遵循这些规范。
```

**后续对话**（无需重复背景）：

```
帮我写一个用户认证模块
```

Agent 会自动生成符合 FastAPI 风格、带类型注解的代码。

## 查看记忆

默认情况下，记忆按用户存储：

```bash
cat backend/.deer-flow/users/{user_id}/memory.json
```

当自定义 Agent 激活时，该 Agent 会维护独立的记忆文件：

```bash
cat backend/.deer-flow/users/{user_id}/agents/{agent_name}/memory.json
```
